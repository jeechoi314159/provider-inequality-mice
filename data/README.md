# data/

Put the Dryad dataset here (or point the `PVSNP_*` variables in `pvsnp_paths.py` elsewhere):

```
data/behaviour_records/Data/...   behavioural records (Dryad 02_behaviour)
data/intermediate/                trial-level tables (Dryad 02_behaviour/intermediate)
data/lfp_processed/               processed LFP arrays (Dryad 04_lfp_processed)
data/chemogenetics/               DREADD records (Dryad 05_chemogenetics)
```
The figure source data go to `figures/data/` (Dryad 01_figure_source_data). Nothing in this folder is tracked by git.
